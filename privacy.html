Privacy Policy

Last updated: October 25, 2026

About This Application

Lawn and Order Backup is a personal utility using rclone to back up files from a local Linux computer to the owner's Google Drive account.

Data Access

The application accesses Google Drive only with the account owner's authorization to create, read, and update backup files.

Data Storage

Backup files are stored in the owner's Google Drive account. Authentication credentials are stored locally by rclone.

Data Sharing

The application does not sell or share personal data with third parties. It is not offered as a public service.

Data Control

The account owner can remove backup files from Google Drive and revoke access through their Google Account security settings.
